when I search http://localhost:5000/api/hello  on browser it sends a request(req) to Express and then express sends a response(res) to the browser and this is REST api.

An API is a way for two pieces of software to communicate with each other.

REST is a set of conventions for designing APIs that communicate over HTTP.

| Method    | Meaning          | Example            |
| --------- | ---------------- | ------------------ |
| GET       | Get data         | Get a user's notes |
| POST      | Create/send data | Create an account  |
| PUT/PATCH | Modify data      | Change username    |
| DELETE    | Delete data      | Delete a note      |


when the url contains localhost, it means to connect to the server running on our own device, port 5000 tells the browser to listen to the backend

app.use(express.json());  --> this parse the json  , it is a middleware

Middleware is code that runs between receiving a request and sending the final response

We can not directly type a post request in browser so we are using thunder client now to give a post request, because it requires data to be given by user   (this concept will be used for registration)


Basic Middleware function:-

const logger = (req, res, next) => {
    console.log(`${req.method} ${req.url}`);
    next();
};

app.use(logger);

next() is used if everything is right, when this function is finished it calls next.

We can send different response based on the status code:

For Example:

    const { title, content } = req.body;
    
    if(!title || !content){
       return res.status(400).json({
            message: "Both Title and Content are required!!"
        });

    }else{

    res.status(200).json({
        meassage: "Note Received!",
        note: req.body
    });
}
});

this piece of code means that the req.body should containt title and content both if any of them is missing there will be status code 400

const { title, content } = req.body;    --> this extracts title and content from req.body and create a const with that name

it is equivalent to :-
const title = req.body.title;
const content = req.body.content;


SQL code :- 
CREATE TABLE notes (
    id SERIAL PRIMARY KEY,
    title VARCHAR(255) NOT NULL,
    content TEXT NOT NULL
);

creates a table notes, which has id, that will identify every unique note, SERIAL increases the id number automatically when a new note is created, title that can have maximum 255 character and NOT NULL means that those fields can not be empty

Now we can create another table for users and then connect it with notes table: 
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(255) UNIQUE NOT NULL,
    password TEXT NOT NULL
);

here UNIQUE means that 2 users cannot have a same email.

Now for passwords we must do password hashing we should not store the user's password directly into our database, we will install bcrypt for hashing


For the program to remember that a user has logged in and only show their routes and data, we use JWT(JSON web Token) token.
token acts like a temporary proof of authentication.

JWT gives the client a signed piece of information that the server can later verify.
